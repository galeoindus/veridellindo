# Deep audit — 22 November 2026 (v6.10.51)

A whole-repository study: 257 files, 22 HTML pages, 49 modules, 22 stylesheets,
plus the Pages Functions and the worker. Run with the repository's own tools
(`doctor`, `deep-audit`, `check`, `audit-site`, the test suite) and with
independent scans of things those tools do not look at — dead files, dead
exports, duplicate declarations, oversized assets.

## What the repository's own tools report

| Check | Result |
|---|---|
| `node scripts/doctor.mjs` (6 checks) | all pass — 34 s |
| `node scripts/deep-audit.mjs` | no problems, 1 warning (110 `!important` in `mobile.css`) |
| `node scripts/check.mjs` | 42 modules parse, every import resolves, one version everywhere |
| `node scripts/audit-site.mjs` | 22 pages, asset paths and build ids consistent |
| `node --test test/` | 230 passing, 0 failing |

Independent scans found no duplicate element ids, no `<img>` without `alt`, no
broken internal link, and no i18n key that is both defined and unused.

## Found, not changed — with the reason

| Finding | Why it is still there |
|---|---|
| **214 selectors are declared four or more times across the sheets** (`.topbar` 28, `.btn` 26, `.dash-hero` 24, `.bottom-nav` 23, `.source-card` 20). `mobile.css` alone carries 110 `!important` rules. | This is the structural reason a small visual fix keeps needing another override. Consolidating it means rewriting the cascade of fifteen sheets and re-checking every page at six widths — a dedicated change with its own review, not a line in an audit. It is the single most valuable next refactor on this repository. |
| The `amigo-worker/` directory is a second implementation of what `functions/api/chat.js` already does. | It is documented as an optional standalone deployment, so it is not dead — but it will drift from the Pages Function unless one is generated from the other. |
| The credits page is ~10,000 px on a phone. | Readable, and its length is content, not a defect; collapsible sections would be a design decision for you to make. |
